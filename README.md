# Indian Chicken Shop

A responsive online storefront for Indian Chicken Shop in Ghaziabad. Customers can browse fresh chicken cuts, kababs, fish and mutton, review product options and start an order through WhatsApp.

**Live website:** [indian-chicken-shop.vercel.app](https://indian-chicken-shop.vercel.app/)

## Highlights

- Product browsing across chicken, kabab, fish and mutton categories
- Product search and shopping-cart interface
- WhatsApp order links for products and categories
- Mobile-friendly storefront and navigation
- Store location, contact and business information
- Search-engine metadata and structured business information

## Built with

HTML · CSS · JavaScript · Vercel

## Project files

- `index.html` — storefront content and product listings
- `style.css` — layout, visual design and responsive styles
- `reviews.js` and `reviews-config.js` — review display configuration
- `assets/` — site imagery and supporting graphics
